A collection of early HTML and CSS projects I worked on while learning basic web development, including a tea shop landing page, 
a website style guide, an HTML cheatsheet, and other layout experiments.

I originally uploaded these files to preserve my work when my hard drive was failing.
They reflect different stages of progress: some are more developed, while others are unfinished, have known issues, or are simply placeholders for ideas.

These projects document some of my practice with page structure, Flexbox layouts, typography, and styling.
